# EO Inventory — phone launcher

Installable home-screen app (PWA) for the EO Inventory Rewst app. Opening this site on a phone prompts to install it;
the installed icon opens the Rewst app (`app.rewst.ai/.../apps/eo-inventory`). No data, no credentials: it only links out.

Source of truth: `aiprojects/project-inventory/launcher-eo-inventory/` (built by EO Automation). Served by GitHub Pages from `main`.
Twin of Electronic-Office/inventory (which opens EO Project Inventory).
